# LazaScope v1.0.0

First public release of LazaScope, a portable Windows utility that shows what a PC is doing and points out anything worth a second look, in plain English.

## Included

- An overview with six lights: Protection, Starts with Windows, Running now, Internet connections, Accounts and remote access, PC health.
- Everything set to start by itself, with its maker, its file and what it is: Run entries, Startup folders, Store apps, scheduled tasks, services, drivers and the settings that get misused to start programs.
- Every running program as a family tree, with the command that started it.
- Every network connection and waiting port, with the program it belongs to.
- The protection of the PC: antivirus, firewall, User Account Control, updates, disk encryption, Secure Boot, the hosts file, administrator accounts, Remote Desktop and remote-control software.
- The extensions in Chrome, Edge, Firefox, Brave, Vivaldi and Opera: where each came from and what it may do.
- What Windows' own logs hold: hardware errors, blue screens with their stop codes, disk faults, and what Microsoft Defender found and was told to skip.
- A reading of every script that starts by itself: what it can be seen to do, and how it begins.
- Names for the far end of a connection where Windows remembers the lookup, the name servers the PC asks, and the proxy setting.
- A SHA-256 fingerprint for every flagged file, and a button that offers to look a file up on VirusTotal by its fingerprint in your own browser.
- **Compare with a report...**, to see what has changed since a report you saved, and **Watch for a minute**, to catch what starts and ends again within seconds.
- Sixty-one written rules that flag what is worth a look, each with its reason, what you can do and the MITRE ATT&CK techniques it may be a trace of, with layers for MITRE's ATT&CK Navigator.
- The installed antivirus asked about scripts and hidden commands, and encoded PowerShell commands decoded.
- A search box over every list, and an analyst mode with the exact evidence behind each row.
- VirusTotal's verdicts in the window, with a free key of your own. Only fingerprints are sent.
- Cryptocurrency wallets: fake wallet extensions, wallet files left where they can be copied, a test for clipboard-stealing malware, and a check of a wallet download.
- A search for recovery phrases saved in text files and documents, confirmed by BIP 39's check or Electrum's. It says where each is and never shows the words.
- A timeline of what happened when, with where downloads came from and Windows' records of what ran.
- The protections you already have and whether each is on, ransomware readiness, and which programs used the camera and the microphone.
- A live watch of programs starting, checked against fifteen detections written as code.
- Signatures checked both inside files and in Windows' catalogues, so that Windows' own files are not mistaken for unsigned ones.
- A report as one self-contained web page, as plain text, or as JSON that carries every fact as it was read.
- A made-up PC to explore with `--demo`.
- The same engine for scripts with `lazascope-cli.exe`.

## Download

Download `LazaScope-v1.0.0-windows-x64.zip`, extract it, and open `LazaScope.exe`. It targets 64-bit Windows 10 and Windows 11. No development tools or installer are required.

`SHA256SUMS.txt` lists the hashes of the ZIP and of both programs. The ZIP also includes the programs' checksums.

## Limits

LazaScope is not an antivirus and removes nothing. It only reads. Nothing leaves the PC unless you ask a file to be looked up on VirusTotal, and then only its fingerprint is sent, never the file. Worth a look means unusual, not harmful, and a clean result is not proof that nothing is wrong. Software that hides inside the core of Windows can hide from it.

It reads the start-up places that matter most and the browsers' extensions, not all of the hundred and more places that Windows has. Without administrator rights a few things cannot be read, among them the scheduled tasks Windows shows to administrators only, and LazaScope says which. Signatures are checked without going online.

See `VALIDATION.md` for the checks that were run and where they stop.
