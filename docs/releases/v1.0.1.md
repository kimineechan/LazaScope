# LazaScope v1.0.1

A fix for Windows 11, and directions that fit both Windows 10 and Windows 11.

## Fixed

- Windows 11 switches some protections on by itself, without always writing a setting. LazaScope now goes by what Windows reports working: Local Security Authority protection by the note Windows writes in its System log when it starts LSASS as a protected process, memory integrity by Windows' Device Guard report, and the vulnerable driver blocklist by Windows 11's default and by memory integrity, which applies it. Before, a fresh Windows 11 PC could be told that Local Security Authority protection was off when it was on.
- A protection switched on but waiting for a restart now says so, and is not counted as working yet.
- A protection's details say how LazaScope knows, where its setting alone does not tell.
- Directions to Settings name the pages of both Windows 10 and Windows 11, and the directions for Local Security Authority protection and the driver blocklist say that Windows 10 has no switch for them.
- The ransomware advice no longer suggests Windows Backup for a copy on a drive you unplug, as Windows Backup copies to OneDrive.

## Windows 11

LazaScope is made for 64-bit Windows 10 and Windows 11, and tested on Windows 10. It is not code-signed. Where Windows 11's Smart App Control is switched on, Windows may refuse to open it, and Smart App Control has no way to allow one program.

## Download

Download `LazaScope-v1.0.1-windows-x64.zip`, extract it, and open `LazaScope.exe`. No installer is needed.

`SHA256SUMS.txt` lists the hashes of the ZIP and of both programs. The ZIP also includes the programs' checksums.

## Limits

LazaScope is not an antivirus and removes nothing. It only reads. Nothing leaves the PC unless you ask a file to be looked up on VirusTotal, and then only its fingerprint is sent, never the file. Worth a look means unusual, not harmful, and a clean result is not proof that nothing is wrong. Software that hides inside the core of Windows can hide from it.
